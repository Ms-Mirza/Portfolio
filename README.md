## Run Locally

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd portfolio-website
```

### 3. Install dependencies


```bash
npm install
```


=======
### 4. Start development server


```bash
npm run dev
```


=======
### 5. Production build

```bash
npm run build
```
